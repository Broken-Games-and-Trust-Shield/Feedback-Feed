# Connect Hub

Can you make a website kind of like discord, were you can make your own server and make different sections with different permissions. You will sign in with your google account. Okay. So a few things. First of all. When you first create an account you should not be part of any server yet. Also you should have the option to leave a server. Also make it so that you can make an acount username and profile picture. Also make it so that you can invite other accounts either via link or via account invite. Make it so that you can also manage and ban people, make certain spaces that only certain people can chat in. Make this called Feedback Feed.
